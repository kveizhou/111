
1. 提取 ldo 的准确库名和 Cell 名
下面是一整条命令：
python3 -c 'import re,sys; from pathlib import Path; d=Path(sys.argv[1]); text=(d/"top_actual.scs").read_text(); hits=re.findall(r"(?m)^\s*ldo\s*\([^)]*\)\s+(oa_\S+)",text); len(hits)==1 or sys.exit("STOP: 无法唯一找到ldo实例"); parts=hits[0][3:].split("__"); len(parts)==2 and all(parts) or sys.exit("STOP: master名称无法准确拆分: "+hits[0]); lib,cell=parts; (d/"ldo_library.txt").write_text(lib+"\n"); (d/"ldo_cell.txt").write_text(cell+"\n"); print("LDO_LIBRARY="+lib); print("LDO_CELL="+cell)' "$st_diag"
紧接着执行：
set st_extract_rc = $status
echo "名称提取退出码=$st_extract_rc"
预期：
LDO_LIBRARY=服务器读取出的实际库名
LDO_CELL=服务器读取出的实际Cell名
名称提取退出码=0
如果出现 STOP 或退出码不是 0，先停止，把输出发来。
2. 只读检查这个内部 Cell
第 1 步成功后，逐条执行：
set st_ldo_lib = `cat "$st_diag/ldo_library.txt"`
set st_ldo_cell = `cat "$st_diag/ldo_cell.txt"`
set st_ldo_diag = `mktemp -d "$st_run/ldo_context_XXXXXXXX"`
echo "读取对象=$st_ldo_lib/$st_ldo_cell/schematic"
然后完整复制下面这一条命令：
"$st_backend" snapshot --cds-lib "$st_session_cds" --lib "$st_ldo_lib" --cell "$st_ldo_cell" --view schematic --core-subckt "$st_ldo_cell" --device-policy "$st_diag/empty_policy.tsv" --netlist-output "$st_ldo_diag/ldo_actual.scs" --catalog-output "$st_ldo_diag/catalog.tsv" --geometry-output "$st_ldo_diag/geometry.tsv" >& "$st_ldo_diag/read.log"
紧接着执行：
set st_ldo_rc = $status
echo "内部LDO只读检查退出码=$st_ldo_rc"
预期：
内部LDO只读检查退出码=0
如果不是 0，执行下面这条并把输出发来：
tail -60 "$st_ldo_diag/read.log"
3. 显示内部电路
第 2 步退出码为 0 后执行：
cat "$st_ldo_diag/ldo_actual.scs"
